# Backend

Two parts:

- **`app/`** — the FastAPI server. It answers searches and questions, and also serves the website
  in `../frontend/`.
- **`pipeline/`** — the data and model pipeline: standalone scripts, one per step, that build
  everything the server loads (see the project README for the order).

## Run the server

From the **project root** (not this folder), with the virtual environment active:

```powershell
.\.venv\Scripts\Activate.ps1
python -m uvicorn backend.app.main:app --port 8000
```

Open <http://localhost:8000>. First time on a new machine:

```powershell
pip install -r requirements-cpu.txt      # torch + pipeline libraries (from the project root)
pip install -r backend/requirements.txt
```

## `app/` files

| File | What it does |
|---|---|
| `config.py` | All settings, read from the project's `.env` |
| `engine.py` | The search engine: loads padas, vectors and both keyword indexes once; resolves a query to its pada; ranks by keyword + meaning (reciprocal-rank fusion); proposes "same meaning, different words" candidates; finds padas for a question by their Steeks |
| `summaries.py` | One LLM request per search: a one-line reason and a verdict (same / related / different) for every card; the verdicts filter the "different words" section |
| `ask.py` | Ask a question: Punjabi search terms → Steek search → pick 2–3 Shabads → explanation and guidance in the question's language |
| `main.py` | The web routes, plus serving the frontend |

The detailed "Why this match?" explanation comes from `../common/explain_match.py`, shared with the
pipeline's command line, so both give identical explanations.

## API

| Endpoint | Returns |
|---|---|
| `GET /api/health` | status, counts (padas, Shabads, lines), models in use, whether explanations are on |
| `GET /api/search?q=<text>&k=5&d=5` | how the query was read (with its pada), `results`, `different_candidates`, `seconds` |
| `GET /api/summaries?query=<ids>&padas=<ids>` | a reason and a verdict per result pada |
| `GET /api/ask?q=<question>` | 2–3 Shabads that answer the question, an answer, explanations and guidance |
| `GET /api/explain?query=<pada ids>&match=<pada id>` | detailed verdict and explanation from the Steeks |
| `GET /docs` | interactive API documentation (generated by FastAPI) |

## What it needs on disk

- `data/processed/padas.jsonl`, `corpus_pankatis.jsonl`
- `data/embeddings/pada_pada/` — pada vectors from `models/bge-m3-pada`
- `data/embeddings/verse_hn/` — line vectors, used to highlight the best line
- `models/bge-m3-pada/` — loaded only for free text (text not found in the Granth)
- `LLM_API_KEY` in `.env` for explanations and questions (free Groq key; optional)

**Memory:** the server holds about 2 GB. Do not run it together with heavy jobs such as
`evaluate_rerank.py` on the 11.8 GB laptop.
